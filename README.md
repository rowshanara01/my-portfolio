## ⚙️ Run Locally

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended) and npm

### Steps

1. Clone the repository

   ```bash
   git clone https://github.com/rowshanara01/your-repo-name.git
   cd your-repo-name
   ```

2. Install dependencies

   ```bash
   npm install
   ```

3. Create your environment file

   ```bash
   cp .env.example .env
   ```

   On Windows Command Prompt, use `copy .env.example .env`, then add your own values.

4. Start the development server

   ```bash
   npm run dev
   ```

5. Open the address shown in the terminal (usually `http://localhost:5173`)

### Build for production

```bash
npm run build
```

## 🔐 Environment Variables

Copy `.env.example` to `.env` and set your own values. Never commit your `.env` file to GitHub.
